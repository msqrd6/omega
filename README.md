# MONOLITH

モノリスのオブザーバーとしてシンギュラー5体を指揮する、対AI（SOLO）・オンラインP2P対人（ONLINE）タクティクスです。7×7のラプスで敵のフェーズ・アンカーを破壊するか、敵ユニットを全滅させると勝利します。

## 基本ルール・ゲームシステム

- **手番と共通オーダー**: 先攻（P1）・後攻（P2）の手番交代ごとに `TURN` が1進みます。各手番の共通オーダーは移動（`MOVE`）と攻撃（`ATK`）が各1枚で、移動や攻撃の実行には専用オーダー（`EX MOVE` / `EX ATK`）を優先して消費します。
- **ウルトゲージ**: チーム共通ゲージ（`0〜100%`、必要ダメージ `100`）は、共通 `ATK` による通常攻撃で実際に減らしたHP分だけ蓄積します。シールド吸収分、超過ダメージ、`EX ATK` やスキル・パッシブ・設置物・ハザードによるダメージは蓄積対象外です。
- **視点・陣営カラー**: 盤面・UIはオンライン／先攻・後攻を問わず **自軍が常に手前（黄色）、敵軍が常に奥（紫色）** で統一表示されます。
- **SOLOモード編成**: 自軍・敵軍ともに全12体から5体を選択でき、先攻／後攻も選択可能です。「お任せ5体」およびSOLOモード開始時の敵初期編成は、4ロール（`ASSAULT` / `SENTINEL` / `DISRUPTOR` / `SUPPORT`）から各1体以上を含む5体がランダム生成されます。
- **初期配置**: 先攻が手前2行に配置・確定した後、先攻の布陣を見た状態で後攻が対抗配置してバトルを開始します。
- 詳細は [RULEBOOK.md](./RULEBOOK.md)、世界設定は [WORLDVIEW.md](./WORLDVIEW.md) を参照してください。

## プレイ方法

ローカル環境でWebサーバーを起動し、ブラウザでアクセスします。

```bash
# ローカルサーバー起動
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてプレイできます（ESモジュールを使用しているため `file://` 直接起動ではなくローカルサーバー経由で開いてください）。
