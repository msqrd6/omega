# ⚔️ Cyber Tactics (サイバー・タクティクス)

近未来のサイバー空間を舞台にした、1vs1（対人・対AI）のタクティカル・ターン制チェスバトルゲームです。  
7×7の電脳盤面上でユニットと防衛コアを指揮し、**相手の防衛コアを破壊する**か**敵ユニットをすべて破壊（全滅）させた側**が勝利となります。

---

## 🌟 最新アップデート情報
- **【ゲームルールアップデート】新たな勝利条件「敵部隊全滅」の追加！**  
  敵防衛コアの破壊に加え、**「敵ユニットをすべて破壊（全滅）させる」ことでも即座にゲームに勝利**できるようになりました。コアへの直接侵攻だけでなく、敵の主力・召喚戦力を殲滅する制圧戦術での勝利が可能です。
- **新ディスラプターヒーロー【🛸 ハイヴ (Hive)】参戦！**

## 🎮 プレイ方法
ローカル環境でWebサーバーを起動し、ブラウザでアクセスします。

```bash
# ローカルサーバー起動
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてプレイできます。
