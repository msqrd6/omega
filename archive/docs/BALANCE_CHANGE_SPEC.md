# 戦闘バランス変更仕様書

全12キャラクターと召喚ユニット「ビット」、手番表示、状態効果、トキシック・ゾーンの変更仕様を定める。数値差分の比較元は変更前の [RULEBOOK.md](RULEBOOK.md) と [ユニット定義](js/config.js)。

## 共通ルール

- **P** は固有パッシブ、**S** は通常スキル、**U** はウルトを指す。Sのストック数は初期値兼上限。
- **半径と隣接**は現行どおり斜めを含む。半径1は中心を含む3×3、半径2は中心を含む5×5。「周囲8マス」は中心を除く。範囲は盤面の端で切る。
- **接敵**とは、周囲8マスに敵ユニット・敵オブジェクト・敵アンカーのいずれかがいる状態を指す。
- **効果対象**は記載したクラスに限定する。ビットはユニットとして扱う。
- **このターン中**の効果は付与した手番の終了時に失効する。自軍の手番中に付与した**1T**は次の相手の手番終了時、**2T**は次の自軍の手番終了時に失効する。ハイヴの攻撃阻害は、付与直後から攻撃者の次に始まる手番の終了まで続く。
- **ターン終了時の処理順**は、**リリーの回復 → ヘイローの回復 → タレット迎撃 → プリズムのレーザー → トキシック・ゾーン → 期限を迎えた状態効果の失効**。状態効果の持続中にターン終了時の回復とダメージを解決する。
- **行動阻害**は通常移動、**攻撃阻害**は通常攻撃をそれぞれ禁止する。**スキル阻害**はP・S・Uすべてを無効にする。阻害中は条件付きの常時パッシブも効果を失い、ターン開始・終了、移動、撃破、被攻撃、召喚などを契機とするパッシブも発動しない。付与済みのシールドと期限付きバフ、獲得済みのEXオーダー、展開済みのゾーンは有効で、それぞれ通常の消費・失効ルールに従う。解除時に常時パッシブの有効条件を再判定し、イベント起点のパッシブは次の該当イベントから発動する。
- 共通オーダー、ウルトの発動条件、ウルトゲージの蓄積ルールは現行ルールを前提とする。専用攻撃オーダー（EX ATK）の攻撃ダメージはゲージ蓄積の対象外。

## 状態効果の加算と表示

状態効果は、選択した駒のインスペクターの `STATES` に付与ごとに表示する。

### 手番と残り時間の表示

盤面の `TURN` は手番が交代するたびに1増やす。先攻の手番が `TURN 01`、後攻の手番が `TURN 02`、次の先攻の手番が `TURN 03` になる。状態欄の `T` は、現在の手番から効果が失効する手番までの交代回数を表示する。現在の手番終了時に失効する項目は残り時間の表記を省く。

| `TURN 01` 時点での失効予定 | 状態欄の表示例 |
| --- | --- |
| `TURN 01` の終了時 | 攻撃力増強 |
| `TURN 02` の終了時 | シールド増強（1T） |
| `TURN 03` の終了時 | 攻撃力増強（2T） |

### 付与ごとの表示と戦闘計算

| 状態効果 | 表示例 | 効果の計算 |
| --- | --- | --- |
| 攻撃力増強 | `+12, +10` | 有効な増強値を基本ATKにすべて加算する。 |
| シールド | `+30, +10` | 有効な各シールドの残量を加算し、合計をシールド耐久値とする。 |
| デバフ | `弱体化, 弱体化, 攻撃阻害` | 受けたデバフをすべて表示する。戦闘計算では、有効なものが1件以上ある種類ごとに1件分の効果を適用する。 |

- **バフの失効** — 付与ごとの持続期間に従う。期限切れや条件外になった項目は表示と合計から外す。ヴェイルは孤立時のP（+10）とU（+10）が同時に有効なら、`STATES` に `+10, +10` を表示し、実効ATKは **18 + 10 + 10 = 38** になる。
- **シールドの消費** — 被ダメージは有効なシールドの合計から吸収する。失効が早い項目から消費し、失効が同時なら先に付与された項目から消費する。各項目には吸収後の残量を表示し、残量0の項目は外す。
- **デバフの重複と解除** — 弱体化が2件ある間も被ダメージ倍率は **1.5倍**。弱体化と攻撃阻害など、異なる種類は同時に有効になる。デバフは付与ごとに失効予定の手番終了時に表示から外れ、種類ごとに最後の有効な付与が消えた時点でその効果が解除される。

## アサルト

### キネシス（KINESIS）

- **P モメンタム・ドライブ** — 自軍ターン中に自身が敵ユニットを撃破したとき、キネシス専用の **EX MOVEを1枚**獲得する。
- **S ライトニング・ステップ（2ストック）** — キネシス専用の **EX MOVEを1枚**獲得する。
- **U ライトニング・ラッシュ** — 自身にキネシス専用の **EX ATKを1枚**付与する。このオーダーでの攻撃はウルトゲージの蓄積対象外。

### ヴェイル（VEIL）

初期配置時のディメンション・ゾーン生成とウルトの吸収回復を、新しい効果に置き換える。

- **P** — 自身の周囲8マスに味方ユニット・オブジェクト・アンカーがいない間、**攻撃力増強+10**。基本ATK18に加算して28になる。
- **S テレポート（2 → 1ストック）** — 自身から半径2マス以内の空きマスを1つ指定し、そこへワープする。
- **U** — 自身に**攻撃力増強+10（このターン中）**と**シールド+20（1T）**を付与する。

### ブラスト（BLAST）

反撃を10 → 5 DMGに変更する。通常スキルは地雷設置から直接砲撃に変更し、ウルトは自己中心型から中心マス指定型に変更する。

- **P カウンター・デトネーション** — 敵ユニットの通常攻撃を受けたとき、攻撃してきたユニットに即座に **5 DMG** を与える。シールドが攻撃を全吸収してHPダメージが0の場合も発動する。通常攻撃でブラストのHPが0になった場合も、その攻撃に対する反撃を処理する。
- **S（2 → 3ストック）** — 自身から半径2マス以内の敵ユニットまたは敵オブジェクトを1体指定し、**10 DMG** を与える。
- **U マキシマム・エクスプロージョン** — 自身から半径2マス以内の任意のマスを1つ指定する。空きマス、駒がいるマス、自身の足元を指定できる。そのマスを中心とした半径1マス（3×3）内の敵ユニット・敵オブジェクト・敵アンカーすべてに **30 DMG** を与える。現行の自傷10 DMGは削除する。

## ディスラプター

### グリッチ（GLITCH）

通常スキルを味方との入れ替えワープに変更し、ストックを2 → 1に減らす。ウルトの攻撃阻害をスキル阻害に変更する。

- **P ディメンション・チャージ** — 自身がワープしたとき、着地点から半径1マス以内の敵ユニット全員に**弱体化（被ダメージ1.5倍、このターン中）**を付与する。
- **S グラビティ・ワープ（1ストック）** — 盤面上の自身以外の味方ユニット1体を選び、両者の位置を入れ替える。味方ビットも選択できる。グリッチの着地先を基準にPが発動する。
- **U ディメンジョン・ワープ** — 盤面上の任意の空きマスへワープし、着地点から半径1マス以内の敵ユニット全員に**スキル阻害（1T）**を付与する。ワープによりPの発動条件も満たす。

### ハイヴ（HIVE）

撃破時の阻害を行動阻害 → 攻撃阻害に変更する。通常スキルの召喚条件をアサルト周囲 → 接敵中の味方ユニット周囲に変更する。

- **P ニューロ・カウンター** — 自身が召喚したビットを破壊した敵ユニットに**攻撃阻害**を即時付与する。攻撃者の次に始まる手番の終了まで持続する。攻撃者が自身の手番中にビットを破壊した場合は、その手番の残りも通常攻撃ができず、付与直後の状態欄には `攻撃阻害（2T）` と表示する。
- **S ビット・デプロイ（2ストック）** — 接敵している、術者本人以外の味方ユニットの周囲8マスにある空きマスへビットを1体展開する。接敵している味方ビットも召喚位置の基準にできる。
- **U スウォーム・オーバードライブ** — 盤面上の任意の空きマスへビットを1体展開した後、そのビットを含む自軍の全ビットに**シールド+10（1T）**と**攻撃力増強+5（このターン中）**を付与する。現行のシールドは+15 → +10。HPの増加量は0。

### ビット（BIT）

- **P 自律ドライブ** — 展開時と毎自軍ターン開始時に、ビット個体専用の **EX ATKを1枚**獲得する。
- **S デリート（1ストック）** — 自身を破壊する。表示名を現行の「自壊」から変更する。

### プリズム（PRISM）

トレース付与とマーク対象への発動を、斜め方向への直接照射に置き換える。貫通レーザーは選択方向の盤端まで進み、途中の駒を貫通する。

- **P** — 自軍ターン終了時、自身から斜め4方向へ貫通レーザーを放ち、各射線上の敵ユニット・敵オブジェクトすべてに **5 DMG** を与える。
- **S（2ストック）** — 斜め4方向から1方向を指定し、その射線上の敵ユニットすべてに**行動阻害（1T）**を付与する。
- **U** — 斜め4方向から1方向を指定し、その射線上の敵ユニット・敵オブジェクト・敵アンカーすべてに **35 DMG** を与える。

## サポート

### ネクサス（NEXUS）

リンク付与とリンク対象への発動を、シールド数に連動するパッシブと、直接指定するスキルに置き換える。

- **P** — シールドが付与されている味方ユニット1体につき自身の攻撃力が **+2（最大+10）**。ネクサス自身と味方ビットも数える。シールドの付与・消失に応じて増加量を再計算する。
- **S（2ストック）** — 盤面上の任意の味方ユニット1体を指定し、**シールド+10（2T）**と**攻撃力増強+5（このターン中）**を付与する。ネクサス自身や味方ビットも選択できる。
- **U** — 盤面上の任意のマスを1つ指定し、そのマスを中心とした半径2マス以内の味方ユニット・味方オブジェクト・味方アンカーすべてに**シールド+15（2T）**を付与する。現行のリンク条件、デバフ解除、攻撃力増強を置き換える。

### ヘイロー（HALO）

基本ステータスとP・S・Uの個別効果は現行の内容を引き継ぐ。

- **P バイタル・オーラ** — 自軍ターン終了時、自身の半径1マス以内で現在HPが最も少ない負傷した味方ユニット1体を **5 HP** 回復する。
- **S サンクチュアリ（2ストック）** — 自身の半径1マス以内にいる味方ユニット全員を **20 HP** 回復する。
- **U レスキュー・ワープ** — 任意の自軍ユニットの周囲8マスにある空きマスへワープし、着地点を中心にサンクチュアリを即時発動する。Sのストック消費は0。

### リリー（LILY）

パッシブの回復対象に味方オブジェクトを追加する。通常スキルとウルトに異常状態解除を追加し、ウルトのチームゲージ直接チャージを廃止する。

- **P ナノ・エンハンスメント** — 自軍ターン終了時、敵陣に向かう前方一直線に回復パルスを放つ。最初に味方ユニットまたは味方オブジェクトに当たると、その1体を最大 **5 HP** 回復して止まる。対象がHP満タンの場合も止まる。敵駒または味方アンカーに当たると、回復量0でそのマスに止まる。
- **S ライフ・リペア（2ストック）** — 自身の半径3マス以内の味方ユニットのうち、**HPが減っているか、デバフがある**駒を1体指定する。対象を最大 **30 HP** 回復し、付与されたデバフをすべて解除する。
- **U オーバーチャージ・オーラ** — 味方ユニット全員を **20 HP** 回復し、付与されたデバフをすべて解除する。現行の15 HP回復とゲージ+30を置き換える。

## センチネル

### ウォーデン（WARDEN）

- **P バンカー・スナイパー** — 味方オブジェクトまたは味方アンカーが周囲8マスにいる間、自身に**攻撃力増強+5**を付与する（基本ATK15 → 20）。
- **S フォース・バリケード（3ストック）** — 自身から半径2マス以内の空きマスへ**バリケード（オブジェクト、HP30・ATK0）**を1つ設置する。
- **U** — 自身と自軍アンカーに距離を問わずそれぞれ**シールド+20（2T）**を付与し、自身の周囲8マスの敵ユニット全員に**行動阻害・攻撃阻害・スキル阻害（各1T）**を付与する。

### ヴァルカン（VULCAN）

ウルトのダメージを25 → 20に変更し、敵アンカーを対象に追加する。

- **P クロスファイア・リンク** — 自身が設置したタレットの破壊時、通常スキルのストックを1回復する。ストックがある間、自身に**攻撃力増強+10**を付与する（基本ATK15 → 25）。
- **S セントリー・タレット（1ストック）** — 自身から半径2マス以内の空きマスへ**タレット（オブジェクト、HP10・ATK10）**を1基設置する。自軍ターン中は破壊ボタンで自軍のタレットを破壊でき、その破壊もPの発動条件を満たす。
- **U フォートレス・プロトコル** — 自軍タレットを1基指定し、タレットから半径2マス以内の敵ユニット・敵オブジェクト・敵アンカーすべてに **20 DMG** を与える。

### スモッグ（SMOG）

パッシブを自軍の毒床上で発動するシールドと常時ATK増強に変更し、スキルを地雷設置からトキシック・ゾーンの直接展開に変更する。

- **P トキシック・インフェクション** — 自軍ターン開始時に自軍のトキシック・ゾーン上にいれば、自身に**シールド+10（このターン中）**を付与する。また、自軍のトキシック・ゾーン上にいる間は常時**攻撃力増強+5**が有効になる（基本ATK15 → 20）。ゾーンに入った時点でATKが増加し、離れるかゾーンが消滅した時点で増加分が失効する。
- **S（3ストック）** — 自身から半径2マス以内の任意のマスを1つ指定し、トキシック・ゾーンを展開する。駒がいるマスや既存のゾーンがあるマスも指定できる。
- **U バイオハザード** — 自身の足元および周囲8マスに毒ガスを放ち、範囲内の**敵ユニット全員**に **10 DMG** を与えてトキシック・ゾーンを上書き展開する。

## トキシック・ゾーン

ゾーンを展開した陣営から見て敵にあたるユニットがゾーン上にいる場合、**P1・P2それぞれのターン終了時**に **5 DMG** を与える。1ラウンドを通して同じ敵ユニットがゾーンに滞在すれば、合計2回ダメージが発生する。オブジェクト・アンカーへの継続ダメージは0。現行の、滞在中の敵ユニットのターン開始時に10 DMGを与える処理を置き換える。

ハザードは1マスに1つ。スモッグのS・Uで新しいゾーンを展開すると、そのマスの既存ゾーンを上書きする。スモッグが撃破されると、そのスモッグが展開したゾーンはすべて消滅する。

## 技名とルール一覧

個別仕様で新名称を指定した技は、その名称を使う。新名称の指定がない技は現行名を引き継ぐ。発動方法と効果の説明は新仕様に合わせる。

今回の変更で生成元がなくなるディメンション・ゾーン、ブラスト・マイン、トキシック・マイン、トレース、リンクをルール一覧から削除する。
